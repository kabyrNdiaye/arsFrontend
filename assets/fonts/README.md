# Police Source Serif Pro

## Téléchargement

Pour utiliser la police **Source Serif Pro** dans ce projet, vous devez télécharger les fichiers de police et les placer dans ce dossier.

### Étapes :

1. **Téléchargez Source Serif Pro** depuis l'un de ces sites :
   - [Google Fonts](https://fonts.google.com/specimen/Source+Serif+Pro)
   - [Font Squirrel](https://www.fontsquirrel.com/fonts/source-serif-pro)
   - [Adobe Fonts](https://fonts.adobe.com/fonts/source-serif)

2. **Extrayez les fichiers** et copiez les fichiers suivants dans ce dossier (`assets/fonts/`) :
   - `SourceSerifPro-Regular.ttf` (weight: 400)
   - `SourceSerifPro-Bold.ttf` (weight: 700)

3. **Structure finale** :
   ```
   assets/
     fonts/
       SourceSerifPro-Regular.ttf
       SourceSerifPro-Bold.ttf
   ```

4. **Exécutez** :
   ```bash
   flutter pub get
   ```

## Alternative : Utilisation avec google_fonts

Si vous préférez ne pas télécharger les fichiers manuellement, le package `google_fonts` peut charger la police dynamiquement. Cependant, cela nécessite une connexion internet lors du premier chargement.
